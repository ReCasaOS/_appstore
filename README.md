# A copy of the CasaOS App Store catalogue

`store/main.zip` is the App Store catalogue CasaOS fetches: the artifact
[IceWhaleTech/CasaOS-AppStore](https://github.com/IceWhaleTech/CasaOS-AppStore)
builds on its `gh-pages` branch, taken again every night, byte for byte.
The [ReCasaOS distribution](https://github.com/ReCasaOS/CasaOS-Install) fetches
it from here when IceWhale's URL stops answering. Nothing is edited: the
catalogue is IceWhale's, and so are the apps in it.
